# MindsPage Code > Ephemeral code scratchpad with synchronous AI code reviews. Built for autonomous coding agents to drop code, get a structured review back in seconds, fix the issues, and repeat — without auth setup or accounts. Default review model: `deepseek/deepseek-v3.2`. The review is opinionated (locked to DeepSeek in the UI) but the API accepts any OpenRouter model id. ## Agent loop (the canonical workflow) 1. **Create a session.** `POST /api/code` with `{"code": "...", "language": "python", "autoReview": true}`. - Set `autoReview: true` to get the first review back inline as `firstReview` (saves a round-trip). - Save `sessionKey` and `claimToken` from the response — they are returned only once. - Read `nextSteps` in every response. It is a plain-English instruction list for what an agent should do next. 2. **Check the verdict.** `GET /api/code/{slug}/status` returns `reviewState`, `criticalCount`, `highCount`, `latestScore`, and `nextSteps`. Possible `reviewState` values: - `unreviewed` — no review has run yet. - `has_critical` — apply the fixes and iterate. - `has_high` — apply the fixes and iterate. - `clean` — no critical or high issues; you can stop. - `review_failed` — last review errored; retry. 3. **Iterate.** When the review is not clean, apply the fixes and call `POST /api/code/{slug}/iterate` with `{"code": " "}` and `Authorization: Bearer `. This updates the code and re-runs a review in one round-trip. Repeat until `reviewState` is `clean`. 4. **Optional: claim** to extend lifetime. `POST /api/code/{slug}/claim` with the one-time `claimToken` and `extendTo` in `{7, 30, 90}` days. ## SDKs - Node: `npm install @mindspage/code`. See `MindsPageCodeSession.iterate()` and `reviewAndAssertClean()` (throws `ReviewNotCleanError` when issues remain). - Python: `pip install mindspage-code`. See `MindsPageCodeSession.iterate()` and `review_and_assert_clean()` (raises `ReviewNotCleanError`). ```python from mindspage_code import create_session, ReviewNotCleanError info, session = create_session(code=src, language="python", auto_review=True) review = info["firstReview"] for _ in range(5): if review and not [i for i in review["issues"] if i["severity"] in ("critical", "high")]: break fixed = apply_fixes(src, review) # your agent's fix step out = session.iterate(code=fixed) src, review = fixed, out["review"] ``` ## Endpoints (root: `https://mindspage.com/api`) - `POST /code` — create. Body: `{code, language?, expiresIn?, autoReview?, model?, focus?}`. Returns `{slug, sessionKey, claimToken, firstReview?, nextSteps}`. - `GET /code/{slug}` — fetch session. - `GET /code/{slug}/status` — review-state summary + nextSteps. **No auth.** - `PATCH /code/{slug}` — update code/language. Auth: `Bearer `. - `POST /code/{slug}/reviews` — synchronous review. Auth required. Returns `{...review, nextSteps}`. - `POST /code/{slug}/iterate` — update code AND review in one call. Auth required. Returns `{session, review, nextSteps}`. - `GET /code/{slug}/reviews` — list all reviews (newest first). - `GET /code/{slug}/events` — activity log (newest first). - `POST /code/{slug}/claim` — extend lifetime with the `claimToken`. ## Limits & defaults - Max code size: 200 KB. - Default lifetime: 180 minutes. Allowed: 10, 30, 60, 180, 720, 1440 minutes. - Review timeout: ~60 seconds. - Two tokens are returned only once at creation: `sessionKey` (long-lived bearer) and `claimToken` (one-time, for lifetime extension). ## Full docs - HTML guide: - OpenAPI spec: (or read `lib/api-spec/openapi.yaml` in the repo). ## Static site hosting (Next.js export, Astro, Vite, plain folders) Upload a built static site (folder of HTML/CSS/JS) as a single `.zip` and get a public URL. **No SSR, no API routes, no middleware** — only files. For Next.js, build with `output: "export"` and `images: { unoptimized: true }`, then `zip -r site.zip out/`. - `POST /api/sites` — multipart/form-data, field `site` = the .zip. Optional `expiresIn` (minutes). Returns `{slug, url, sessionKey, indexPath, notFoundPath, fileCount, totalBytes, expiresAt}`. Save `sessionKey`; it is needed to replace or delete the site. - `GET /api/sites/{slug}` — metadata. - `DELETE /api/sites/{slug}` — delete (Auth: `Bearer `). - `POST /api/sites` with `Authorization: Bearer ` and `slug= ` — atomic re-upload (replace the tree). - `GET /site/{slug}/{path...}` — public serving. Pretty URLs (e.g. `/about` → `about/index.html`) and trailing-slash directory indexes work. Unknown HTML paths fall back to `404.html` (status 404) if present, otherwise to `index.html` (status 200) for client-side routers. Hash-named assets under `_next/static/*` get `Cache-Control: public, max-age=31536000, immutable`. Curl example: ```bash curl -F "site=@out.zip" -F "expiresIn=180" https://mindspage.com/api/sites ``` Limits: zip up to 25 MB, uncompressed total up to 50 MB, up to 500 files, single file up to 10 MB.
